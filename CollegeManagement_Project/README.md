# CollegeManagement

Демонстрационный веб-проект управления колледжем на **ASP.NET Core MVC (.NET 8)**.

## Что реализовано
- Главная страница с краткой статистикой.
- Авторизация администратора.
- Страницы студентов, преподавателей и учебных групп.
- Добавление и удаление студентов.
- Электронный журнал: добавление и удаление оценок с проверкой диапазона 2–5.
- Учёт посещаемости.
- Административная панель.
- Модели и сервисы, демонстрирующие `public`, `private`, `protected`, `internal`, `protected internal` и `private protected`.
- Стартовые демонстрационные данные.

## Запуск
1. Установите .NET 8 SDK.
2. Распакуйте архив.
3. Откройте терминал в папке проекта.
4. Выполните:

```bash
dotnet restore
dotnet run
```

5. Откройте адрес, который появится в терминале (обычно `https://localhost:xxxx` или `http://localhost:xxxx`).

## Демо-вход
- Логин: `admin`
- Пароль: `12345`

## Важно
Это учебная демонстрационная версия: данные хранятся в памяти и сбрасываются при перезапуске приложения. Для реального использования следует подключить базу данных, полноценную ASP.NET Core Identity, роли и защиту административных действий. Некоторые действия доступны без входа, чтобы было удобно проверять учебные разделы.
